# 参与改进

## 提交反馈

最有帮助的反馈包含原始提问、让你不舒服的回答，以及你希望它怎样表达。可以附上模型、推理强度和使用工具，方便复现。

欢迎直接修改规则或补充案例。核心文件是 [SKILL.md](../skills/direct-answer/SKILL.md)，已有案例在 [examples.md](../skills/direct-answer/references/examples.md)。

## 比较规则调整

选择同一批输入，固定模型、推理强度和工具环境，分别运行调整前后的技能，保存完整输出。重点检查：

- 是否回答了用户的问题，给出需要的判断。
- 假想反驳、重复限定和泛化收尾是否减少。
- 必要的纠错、条件、归因和作者立场是否完整。
- 长对话中已经解决的提醒是否又出现。
- 用户真的要求评测或风险说明时，是否能完整回答。

按句子的用途判断，不只统计否定词或字数。生成任务与改写任务分别记录；手动提醒后的结果另行记录。

案例集包含教学示例和用户反馈，目标回答用于说明修改方向。提交模型运行结果时，注明输入、技能版本、模型配置和实际输出。
